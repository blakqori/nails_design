# Nails Design – Nail Salon Website & Booking System

**A responsive nail salon website with an appointment booking system currently under development.**

🌐 **Live Website:** https://blakqori.github.io/nails_design/

💻 **GitHub Repository:** https://github.com/blakqori/nails_design

## Project Overview

Nails Design is a web development project designed to provide a modern and user-friendly digital experience for a nail salon.

The project focuses on responsive web design, intuitive navigation, service presentation, and the development of an automated appointment booking system.

The goal is to build a full-stack application that allows customers to explore salon services and book appointments online.

## Planned Booking Features

The appointment booking system is intended to support:

- Online appointment requests
- Service selection
- Available appointment dates and times
- Customer information management
- Appointment status management
- Prevention of overlapping bookings

These features are currently under development and are not yet available in the live website.
